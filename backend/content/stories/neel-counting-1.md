# Counting with Neel: Numbers 1-5

*Shreya decides to teach Neel how to count using fun, colorful objects.*

Shreya pulled out a basket of colorful blocks.

**"Neel, let's count!"** she said cheerfully.

## One Block 🔴

Shreya placed one red block on the table.

**"One!"** said Neel, touching it gently.

**"Good job!"** said Shreya, clapping.

## Two Blocks 🔵🔴

Shreya added one blue block next to the red one.

**"Now, Neel, how many blocks?"**

**"One, two!"** counted Neel carefully.

**"Perfect!"** cheered Shreya.

## Three Blocks 🟡🔵🔴

Shreya added a yellow block.

**"One, two, three!"** Neel was getting better!

## Four Blocks 🟢🟡🔵🔴

**"And now?"** asked Shreya, adding a green block.

**"One... two... three... four!"** counted Neel, touching each block.

## Five Blocks 🟣🟢🟡🔵🔴

Finally, Shreya added a purple block.

**"One, two, three, four, FIVE!"** Neel shouted with joy, clapping his hands.

Shreya hugged her little brother. **"You can count to five, Neel! You're so smart!"**

Neel hugged the blocks. **"Again! Again!"**

Learning to count had made Neel very happy!

## Learning Objectives:
- Recognize numbers 1-5
- Practice one-to-one correspondence
- Build counting skills
- Celebrate success!
